# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Borescope is a static call-path engine — a single Rust binary that indexes any repo into a symbol/call graph via tree-sitter, enriches it with git history signals, and answers path queries rendered as weighted call trees. See `SPEC.md` for verifiable requirements and `docs/SPEC.md` for the full product+technical spec.

## Key implementation constraints

- **tree-sitter runtime version must be pinned** (0.26.x line); grammar crates must match. Mixing versions silently breaks parsing.
- **Grammar ABI lock**: every grammar crate's tree-sitter dependency must resolve to the same version as the runtime. Use `[patch]` in the workspace `Cargo.toml` if needed.
- **Git integration shells out** to `git` (not libgit2/gitoxide). Abstract behind a trait so the backend can be swapped later.
- **Storage is SQLite** via `rusqlite` (bundled feature). Schema versioned in `meta` table. Changing CLI or JSON output must never require a storage-format change — the store is an implementation detail.
- **JSON output (`-o json`) is a stability contract** under `"schema": 1`. Additive changes only; breaking changes require a new schema version number.

## Milestones (build order)

M0: `bs-git` + `bs-core` store + git commands (`hotspots`, `coupled`, `age`, `smells`, `map --weight churn`). No tree-sitter.  
M1: `bs-extract` — tier-1 grammars, query packs, `index`, `map --zoom fn`.  
M2: `bs-link` — confidence model, `paths`, `callers`, tree/folded/json renderers, span-level git attribution.  
M3: `diff`, `branch`, `--weight diff`, HTML renderer.  
M4: Tier-2 grammars, `--grammar-path`, release builds, `skill/` package.

## Testing approach

- Each tier-1 language has a fixture repo in `testdata/` with a checked-in ground-truth call graph JSON. Extraction tests assert precision ≥ 0.9 on confidence-≥0.7 edges.
- Renderer tests use `insta` snapshot testing with `--no-color` output.
- Git miner tests run against a scripted synthetic history (deterministic commits generated by a test script).
- Diff tests use fixture repos with two known branches; assert `+/-/~` frame classification.
- CI smoke matrix: index tree-sitter's own repo + one Go project; assert exit 0 and non-empty graph.

## Exit codes

```
0  success
1  runtime error
2  usage error
3  ambiguous target — candidates listed on stderr as JSON
4  index missing or corrupt (with recovery hint)
5  grammar unavailable for requested file
```
